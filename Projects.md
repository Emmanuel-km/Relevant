# Text Encryption / Decryption Tool

**Simple client-side tool to encrypt and decrypt text using your own secret key.**

🔗 **Live Demo:** [https://simple-encryption-decription-tool.onrender.com/](https://simple-encryption-decription-tool.onrender.com/)

---

## What it does

- Encrypt any text with a personal key
- Decrypt text using the same key
- All processing happens in your browser - nothing is sent to a server

---

## How to use

1. Enter your secret key
2. Type or paste your text
3. Click **Encrypt** or **Decrypt**
4. Copy the result

> ⚠️ The same key must be used for both encryption and decryption. Lost keys cannot recover encrypted data.
